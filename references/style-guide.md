# 电源树 / 系统框图 绘图规范

这套规则来自多次评审收敛的结果；违背其中任何一条都会让图变得不可读。
出图前逐条自检，不合格就改图重出。

## 一、硬性规则（违反即返工）

1. **不允许断开**：任何一条连线、母线、支路的两端都必须落在另一条线、器件框或连接器的边界上，
   不得出现悬空端头。母线的两端只能停在“有分支或接器件”的位置。
   *踩过的坑*：总线为了穿过整张图而多伸出一段，末端什么都没接，看起来像断线。
2. **不允许交叉**：走线不得互相穿过。跨板 / 跨区长线改走公共中转（如连接器条带），
   或调整器件排列顺序让路径不交叠。
3. **横平竖直**：只允许水平段与垂直段，禁止斜线。外设到主控用一条水平直线直连。
4. **箭头必须可见**：箭头用固定尺寸（SVG 里 `markerUnits="userSpaceOnUse"`，16 单位），
   **不随线宽缩放**。线宽 8px 时若箭头也放大，会变成一个盖住整条线的黑三角。
   支路折线长度建议 ≥ 50px，太短会被箭头吃掉。
5. **文字不压线**：长度超过 60px 的标注加白色底衬（`text(..., bg=True)`）。
6. **共用总线必须编号 + 配色**：见第三节。

## 二、尺寸与配色

- 画布：电源树 2200×1500，系统框图 2200×1650（可按内容调整，但保持 100px = 1 英寸）。
  这个比例让 Visio 页面正好是 22×15 / 22×16.5 英寸，可按 1:1 打印。
- 线宽分级：主干母线 8px，支路 4px，框图信号线 2.4px，器件边框 1.2～2.4px（IC 主块加粗）。
- 电源树按**电压域**着色：

| 电压域 | 颜色 | 典型用途 |
| --- | --- | --- |
| 9.2V | `#E5007D` 品红 | 升压后人脸/外设模组 |
| 5V | `#C00000` 深红 | PA / 5V LED |
| 3.0–4.25V | `#FFC000` 琥珀 | 电池与系统主干母线 |
| 3.3V | `#00B050` 绿 | 主 3V3 域 |
| 1.8V | `#00B0F0` 青 | IO / Sensor DOVDD |
| 1.5V | `#7030A0` 紫 | DDR 或 Sensor DVDD |
| 0.8V | `#2E75B6` 蓝 | 内核 |

- 系统框图按**总线类型**着色（见第三节表格），IC 块统一淡蓝底 + 蓝框。

## 三、电源树画法

- 版式左→右流动：左端输入源（Type-C / 太阳能 / 内机 / 电池）→ 中间充电与总开关 →
  右侧各级 DC-DC / LDO → 末端负载框；右下角放电压域图例。
- 转换器：**实心色块 + 白字**，块内写“位号 + 拓扑 + 输出电压/电流 + 效率”，最多 3 行。
- 负载：**白底黑框圆角矩形**，只写负载名，不写参数。
- 支路标注 `电压_电流`（如 `3.3V_0.50A`），放在线的上方 8～9px。
- 每个电压域只允许一条同色母线；不同域不得共用同一条线。
- 子板电源（如经连接器取电的板）单独画一段子树，馈电线与各支路的箭头要加粗加长。

## 四、系统框图画法

- 按板分层：主板在上、连接器条带居中、外设板在下（或左右分栏），外围器件分列两列。
- 主控（SoC / MCU）用**竖长蓝块**居中，外设用**白底黑框**放两侧，
  每路用**一条水平直线**直连主控侧边，总线名标在线上（带白底）。
- 连接器条带内用 ①②③ 编号说明信号组；跨板信号**以条带为中转**，
  两侧各画一段垂直短线，不要让长线绕过整张图。
- 不同 IC 的垂直引线要错开 x 坐标（较长的竖线走外侧），避免相互穿越。
- 右下角放图框标题栏：图名、板别/版本、日期、Rev、Sheet。

## 五、共用总线编号与配色

同一条物理总线（尤其 I2C / UART）挂多个器件时**必须编号**，同编号用同色，
并在角落的“总线分组”说明框里写清编号、上拉阻值、主从与挂接器件。

| 总线类型 | 颜色 | 说明 |
| --- | --- | --- |
| I2C | `#ED7D31` 橙 | 多器件共用时必须分组编号（I2C-1 / I2C-2 …） |
| SPI | `#7030A0` 紫 | 片选独立时通常独占，标注 `SPI-x（独占）` |
| UART | `#00A651` 绿 | 点对点，标注 `UART-x` |
| SDIO | `#0070C0` 蓝 | 标注位宽，如 `SDIO-1（MSC1，1-bit）` |
| MIPI | `#00A0A0` 青 | 标注 lane 数 |
| USB | `#2E75B6` 蓝 | |
| GPIO / 控制 | `#7F7F7F` 灰 | 离散控制与状态，用 ①② 编号 |
| 音频 | `#C55A11` 棕 | I2S / 模拟 |
| 电源 | `#C00000` 红 | 供电与使能 |

- 线上标注要带编号与共用标记，如 `I2C-1 ＋ INT（共用）`、`SPI-1（SFC0，独占）`。
- 器件框内副标题也写编号（如 `I2C-2 从机 ＋ INT`），便于从器件反查总线。

## 六、从原理图提取信息的方法

1. 先光栅化页面，用图看**连线关系**；用文本层检索**网络名、位号、数值**。
2. 电源树信息从这些地方找：充电芯片的 FB/VSEN 分压电阻（算浮充与 MPPT 电压）、
   检流电阻（算充电电流）、DC-DC 的反馈电阻（算输出电压）、LDO 型号（查输出与限流）。
3. 总线分组信息从网络名找：`BLE_I2C_*` / `APT_IIC_*` / `Sensor_*` 这类前缀就是不同总线，
   再看上拉电阻位号确认哪几组是同一物理总线。
4. 框图分层信息从连接器（BTB / Pogo / 排针）的针位表找，明确哪些信号跨板。
5. 图面上标注的电流/效率只在图面确有标注时采用，否则标“待确认”，不要自己编。

## 七、出图前检查清单

- [ ] 每条线两端都落在器件 / 连线 / 连接器上，无悬空端
- [ ] 无斜线，全部横平竖直
- [ ] 无交叉（含跨板长线）
- [ ] 箭头未被线段或器件遮盖，粗细一致
- [ ] 文字标注均有底衬、未压线、未被裁切
- [ ] 共用总线有编号，编号与线色对应，且有说明框
- [ ] 电压域颜色与图例一致
- [ ] SVG / PNG / VSDX / VDX 四份文件同步生成
